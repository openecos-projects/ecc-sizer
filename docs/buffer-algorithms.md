# 缓冲器插入：Path、VG、GOBI、PBBI

四个流程独立运行，也可通过 `--flow path,vg,setup` 顺序组合。算法只生成方案，`repair/buffer.*` 统一处理插入、数量约束、合法化、刷新、验收和回滚。

| 策略 | 修复对象与候选 | 求解方式 | 执行方式 |
|---|---|---|---|
| VG | 按电气违例选网；setup scope 可扩展到负 slack 网 | Placement Steiner 树上的 Van Ginneken 候选传播与剪枝，CPU/CUDA 可选 | 多网完整树组成一个 ECO |
| GOBI | 按电气违例选网 | GPU forest 上并行计算与合并候选 | 多网完整树组成一个 ECO |
| Path | 按 setup/recovery 路径采样与选网 | 负载分组、显式树、延迟预测、实测反馈调度 | 逐候选或不冲突批次试验 |
| PBBI | 缓冲感知 STA 选出的 setup 路径及其旁支，随后处理剩余网 | 跨固定门的路径树 DP，保留 RAT/电容/buffer 数前沿 | 逐路径增量验证，阶段末合法化与完整 STA |

VG 与 GOBI 的算法不同，其求解耗时比不等于相同算法的纯硬件加速比。GOBI 需要可用 GPU；VG 默认 CPU，CUDA 后端不可用时有 CPU fallback。六设计评测会记录实际后端，出现 fallback 不当作成功的 GPU 对照。

## Path 的策略

每轮分别采样 setup 和 recovery 的关键端点，提取路径经过的共享网。对每个网，尝试全负载、关键负载、非关键旁支及空间分组，组合缓冲器型号与位置。路径负责确定优先修哪些网；每个物理候选仍属于一个网，不把经过逻辑门的多个网拼成一棵树。

候选既包括单 buffer，也包括按电容和加权 fanout 约束构造的整网多级树。单 buffer 应用后如形成新的 fanout 违例，可在同一个 ECO 内补树；整棵树一起验证、提交或回滚。旁支隔离可以减轻原驱动负载，但更多层级也会引入延迟。

预测使用 STA Liberty 模型、placement RC、buffer 延迟/slew、下游首级门延迟变化，并考虑异步控制的 recovery 检查。优先比较预测全局 WNS/TNS；若被未修改端点限制而相等，再比较受影响路径裕量与电气风险，最后比较 buffer 数和面积。

`PathPolicy` 管理反馈、校准和候选生成，`PathSchedule` 管理队列、去重与批次。失败证据依赖设计代次与结构，相关网或端点变化后重新开放。预测用于决定先试谁，不能取代实际 STA 验收。Path 当前不调用 VG/GOBI。

## PBBI：论文对应与实现范围

依据 [Sze 等，DAC 2005《Path Based Buffer Insertion》](papers/path-based-buffer-insertion/sze-dac2005-path-based-buffer-insertion.pdf) 第 2–4 节实现固定门尺寸的缓冲插入流程。`algorithms/pbbi.*` 使用独立的路径树和候选前沿，不调用已有 Path 策略。**固定门尺寸只表示不做第 5 节的联合 sizing；全网络缓冲感知 AT/RAT、逐路径更新和未处理网收尾仍属于核心流程，不能省略。**

### 当前执行顺序

1. 为可编辑信号网构建 placement Steiner 树，使用引用文献 [6] 的 BELT 解析预测。按障碍边界切分线段，保留障碍内部节点和旁支电容；预测不再调用 VGDP，也不受候选前沿影响。预测与求解使用同一曼哈顿几何嵌入。
2. 将预测的逐 sink 缓冲延迟及原驱动负载修正临时标注到 OpenSTA 的 max delay arcs，传播全网络 AT/RAT。时钟、SDC、exceptions 和重汇聚均由 OpenSTA 处理，不另建一套自定义 timer。不支持编辑的网保留真实延迟。若预测 WNS 仍为负，则成本优化以该预测可达 slack 为目标，统一平移规划 RAT；否则目标为零 slack。原 SDC 和真实验收不变。
3. 在缓冲感知 STA 上选择最多 64 条 setup 路径，包括预测已经可行的路径；按关键程度分配共享网，重叠处切成独立路径段。先复制路径 pin 值，再查询旁支时序，避免持有失效的 STA 路径对象。
4. 将路径上各网通过强制固定门节点连接。电容在门处重置，RAT 与成本继续传播；旁支 RAT 来自同一全网预测时序，并在有正 useful slack 时应用式 (7)。达到根部 AT 时选择最少 buffer 的候选，否则优先最大 RAT。
5. 返回计划前恢复预测标注的原值及 annotation 标志。执行一条路径后更新真实 placement RC 和 STA，核对 setup/hold/DRV；仅保留实测正收益且不退化的修改。拒绝时恢复该路径，再更新时序。下一次规划使用最新真实设计，并只为尚未处理的网叠加预测。
6. 处理未分配给路径的原始网，使用相同单网 DP。实际电气健康且 slack 已达到规划目标的网已有零成本解，直接保留。每个原始网只处理一次，新插入网不进入续搜。
7. 阶段末统一合法化并执行完整寄生重估、STA 和电气检查；失败则恢复所有暂存修改及布局。预测阶段和逐路径阶段均不移动原有单元，保证未处理网的几何预测可复用。

树回溯生成每个原始网独立的 `BufferTreePlan`，不会跨逻辑门短接，也不会把固定门当作新增 buffer。`pbbi::Planner` 只负责预测、调度和求解，`repair/buffer.*` 管理实际编辑、验证与事务。

### 与论文逐项对照

| 论文内容 | 当前状态 | 剩余差异或限制 |
|---|---|---|
| §3 成本感知 VGDP | 保留电容、RAT、buffer 数，并加入 slew/fanout 状态 | 成本为 buffer 数，符合论文 buffer-only 实验；不是按面积或功耗加权 |
| §4.1 全网络缓冲感知 STA | 已由临时延迟预测 + OpenSTA 全网传播实现 | BELT 按 [6] 的零本征延迟、理想源/负载与无限小旁支隔离假设计算；预测并非实际 NLDM 时序 |
| §4.2 在预测时序上选路径、去重 | 已实现 | 固定最多 64 条，尚无自适应 k；rise/fall 路径选择由 STA 完成，DP 内部仍是标量模型 |
| §4.2 跨固定门的联合树求解 | 已实现 | 门弧以实际 STA 延迟校准，但不随候选的输入 slew 重新查完整 NLDM |
| §4.3 每条路径后的 AT/RAT 更新 | 已实现 | 用实际增量 RC/STA 更新，再叠加未处理网预测；额外加入真实收益与非退化验收，属于工程扩展 |
| §4.3 旁支式 (7) | 使用一致的全网预测 AT/RAT | 非正 useful slack 不放宽约束，分配比例限制在 0–1；不构成任意重汇聚情况下的最优性保证 |
| §4.2 未处理网的单网收尾 | 已实现 | 只覆盖可编辑、有 placement 树的原始网；不可编辑或无树的网保留真实时序 |
| §5、§5.1 联合 gate sizing、sink sizing | 未实现 | 还缺门尺寸候选、旁支输入电容耦合，以及式 (8) 的 sink sizing 修正；不能以额外运行 Setup 等同于论文联合优化 |
| 候选位置与电气模型 | 使用现有 Steiner 线段端点、硬 blockage、Liberty 线性参数 | 已按障碍边界和曼哈顿拐点分段；尚无按线长生成的密集候选网格；完整 footprint 由最终合法化处理；根驱动 slew 与门电容约束的模型仍需校准 |
| PI、多个 scene | 全网 STA 保留其真实约束和延迟 | 当前缓冲插入适配器只支持单 scene、单元输出驱动网；PI 网尚未参与缓冲候选求解 |

### 解析预测与前沿近似

实现对应 [6]《Accurate Estimation of Global Buffer Delay within a Floorplan》（ICCAD 2004）的式 (1)、(5)、(6)、(9) 和图 7，以及 [16]《Making Fast Buffer Insertion Even Faster Via Approximation Techniques》（ASP-DAC 2005）的第 III–V 节。来源记录见 [sources.json](papers/path-based-buffer-insertion/sources.json)。

- BELT：无阻塞段使用 `Rb·C + R·Cb + sqrt(2·Rb·Cb·R·C)`，这里 R/C 为该段总电阻/电容。阻塞段累积 Elmore 延迟，在进入阻塞子树的边界计入驱动整个阻塞子树的电容，自由旁支不承担这个边界驱动项；只有关键通路计入一次 Cb，旁支隔离 buffer 的输入电容按论文假设为零。连续阻塞区小于 Lopt 时使用线性估计，不能对拆分后的每条小边各自忽略。分支阻塞区域按最长入口到出口路径判断，保留该区域的完整旁支电容。
- 对每棵树从合法库选择使线性传播延迟最小的单一理想 buffer；实际 VGDP 仍使用包含本征延迟、最大电容与 slew 约束的真实候选库。论文的理想源/负载假设不等于把物理网表换成理想 buffer。
- PSP/APSP：比较同成本候选的 `q−R·c`。默认电阻为根驱动、路径固定门和候选 buffer 电阻的最小值；倍率大于 1 才是 APSP。原文 §III 的斜率不等号与其算例及 §IV 描述冲突，代码使用定义中的预缓冲裕量支配条件，并验证原文 1223 ps / 11 fF 与 1258 ps / 96 fF 算例。DAC 2005 未给出其调用 [16] 时的电阻倍率，不能声称复现了作者未公开的具体参数。
- SqP：同成本、递增电容/RAT 的三个点，删除位于上凸包下方的中间点。多分支处是论文明确允许的近似，不宣称最优性；额外检查 slew/fanout 维度，避免剪掉唯一电气可行状态。
- 库查找：按 [16] 的 300 项电容表选择“平均驱动→候选 buffer→负载”延迟最小的型号，每个成本组只增加最佳缓冲候选。表范围由整棵候选树的电容上界确定；网格舍入后重新检查电气可行性。当前合法库为非反相 buffer，因此只有非反相表，未加入 inverter/极性变换。

分叉合并按总成本流式生成，使用精确支配索引过滤冗余中间状态，避免先分配完整笛卡尔积。PSP/SqP 仍在完整幸存集合上执行，没有新增近似规则；通过全枚举 Pareto 与笛卡尔积对照验证。

已删除 `max_frontier` 及固定 128 状态截断。`buffer.pbbi.approximate=false` 用于小树完整前沿对照；不会切换预测模型。日志分别记录 PSP/APSP 删除数、SqP 删除数和前沿峰值。公式测试覆盖论文 437.0 ps 障碍算例、阻塞旁支、分段不变性、短障碍、两类剪枝、负载相关库选择及超过 128 个非支配候选。

### 如何判断复现质量

论文 buffer-only 对照采用相同 VGDP 实现，并在相近最差时序下比较 buffer 成本。当前规划目标采用初始缓冲感知 STA 的 `min(0, WNS)`，以免在预测不可达的零 slack 目标上持续选最大 RAT、忽视成本。该预测不是可达性的数学证明，不等于修改 SDC，也不保证或宣称 setup 清零。当前既有 VG、Path 的求解器和策略不同，因此 AES/JPEG 表格用于工程对照，不能单靠“buffer 更少”证明论文的成本优势。摘要中的 71% 对应联合 gate sizing 扩展，也不是当前固定门实现应直接复现的数值。

补齐全网流程后的诊断中，AES 的 21 个路径段在零 slack 目标下均被模型判为不可行，单网收尾产生大量实测拒绝，说明不可达目标与预测误差会共同放大耗时。因此最终采用预测可达目标；诊断运行及旧复测文件不保留。

下一步应先核对逐端点的预测/实际 AT、旁支 RAT 和候选误差，继续用小树完整前沿检查多分支近似的误差。仍需验证预测目标是否准确：如果某个路径段在该目标下仍不可行，当前回退到最大 RAT，最少 buffer 只用于同收益候选的比较。论文评测先用最小延迟缓冲确定可达约束，不能仅凭预测目标相同就宣称实现等价。完整 STA 验收能防止提交退化结果，但不保证预测能够找到高质量候选。联合 sizing 应在固定门流程与模型验证稳定后加入。

```sh
build/src/Sizer design.tcl --flow pbbi --output repaired
build/src/Sizer design.tcl --flow pbbi,drv,setup --output repaired
```

## 接受与停止

Path 默认接受数值上严格的时序正收益，同时保持全局 hold、DRV、面积和非退化约束。接受、排序、停止相互独立：小收益可以接受，但只按收益大小补充续搜额度。每次试验消耗一额度，默认 32；剩余额度不足一次试验时停止，没有墙钟时间上限。

VG/GOBI 选择放得下的完整网方案，不为了插入数额度截断树。应用后默认要求 setup 和 DRV 数量非退化，且至少有时序或电气改善；失败回滚整个 ECO，不自动拆成小批次。

Path 默认逐试验合法化；其阶段末模式以及 PBBI 在建议坐标上使用增量 RC/STA，最后统一合法化并做完整验证，失败会恢复整阶段输入。返回前必须保证 RC/STA 与网表一致。

## 日志与性能

Path 的 info 日志报告开始、接受修改、结束、最终合法化结果；debug 报告具体候选、拒绝原因、实测收益和续搜额度。日志按事件触发，不使用固定时间周期。VG/GOBI 报告选网、求解、应用耗时以及后端。GOBI 的 debug 汇总还包括 frontier 数量、峰值内存、压缩节省和 GPU 内存使用。独立评测重新读入已提交输出。
